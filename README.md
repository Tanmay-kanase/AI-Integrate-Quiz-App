# AI-Integrated Quiz App 🧠🚀

Welcome to the **AI-Integrated Quiz App**, a comprehensive, smart evaluation platform designed to help users master any subject. This application leverages AI to generate dynamic, personalized quizzes from PDFs or text topics. It also features a fully functional coding assessment environment and built-in proctoring security.

## ✨ Key Features

- **AI-Powered Quiz Generation:** Automatically generate targeted questions by uploading a PDF document or simply entering a topic.
- **Diverse Assessment Types:** Supports traditional Multiple Choice Questions (MCQs) and integrated coding assessments with an in-browser IDE.
- **Smart Proctoring & Anti-Cheat:** Features strict window-focus monitoring. If a user navigates away from the quiz tab, a security warning is triggered, and the quiz is automatically submitted.
- **Interactive Dashboard:** View available quizzes by category, track time with a live countdown, and navigate questions seamlessly with a color-coded status palette.
- **Pre-Quiz Guidelines:** Clear, structured rules ensuring users are ready and aware of the strict time limits and no-AI assistance policies before starting.

## 🛠️ Tech Stack

- **Frontend:** Angular (Routing, Reactive Forms, State Management , guards , interceptors)
- **Backend:** Node.js (REST APIs, Assessment Evaluation)
- **AI Integration:** Ollama models Cloud.
- **Database:** MongoDB
- **Certificate:** html2canvas
